TurtleStation Dashboard v1.0

Um frontend de altíssimo nível para emuladores e jogos retro, rodando diretamente no Linux.

Desenvolvido para proporcionar uma experiência visual idêntica à do Steam Deck (TurtleStation), otimizado para navegação rápida e simples, com ou sem teclado/gamepad.

Stack Tecnológica:
  • Backend: Node.js + Express
  • Design System: CSS Custom Properties, Glassmorphism & Flexbox/Grid
  • Mecanismo de Controle: Vanilla JavaScript Keyboard Mapper
  • Media Scraper: Libretro Thumbnails Database & Steam Web API
